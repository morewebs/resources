# Prompts

Standalone prompt templates and prompt snippets — reusable text that isn't a full executable skill workflow.

- One file (or one directory) per prompt, named in kebab-case.
- Markdown preferred; keep a short header stating what the prompt is for and any variables/placeholders it expects.

Skills live in [`../skills/`](../skills/); if a prompt grows helper scripts or multi-step logic, promote it to a skill instead.
